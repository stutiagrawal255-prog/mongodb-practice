# MongoDB Practice

This repository contains MongoDB practice queries, shell commands, and hands-on exercises.

## Structure

### [`CRT-1/`](CRT-1)
- `MongoDB Day 1.txt`: document creation, querying, projections, and nested fields
- `MongoDB Day 2.txt`
- `MongoDB Day 3.txt`

### [`CRT-2/`](CRT-2)
- `MongoDB Class - Monday Work Log.txt`: indexing lab (`mongodb_index_lab`): single-field, compound, multikey, unique, hidden indexes and `explain()` plans
- `MongoDB Class - Tuesday Work Log.txt`: replication lab (`replication_lab`): replica set status, `hello`, read preferences
- `MongoDB Class - Wednesday Work Log (MongoDB Shell).txt`: `StudentDB` setup with `students` and `courses` collections, CRUD updates, indexes, and aggregation
- `MongoDB Class - Wednesday Work Log (PowerShell Backup).txt`: backing up and restoring `StudentDB` with `mongodump` / `mongorestore`
- `MongoDB Class - Thursday Work Log (MongoDB Shell).txt`: `StudentDB` CRUD, unique indexes, `dropIndex`, sorting/filtering, aggregation reports
- `MongoDB Class - Thursday Work Log (PowerShell).txt`: Node.js + Express + Mongoose REST API (students/courses), API testing with `Invoke-RestMethod`, and backup/restore to a test database

## Topics Covered
- Database creation and switching
- Document insertion (`insertMany`)
- Filtering and projection
- Working with nested objects and arrays
- Indexes and query plans
- Replica sets and read preferences
- CRUD operations (`updateOne`, `updateMany`, `deleteOne`)
- Unique indexes and dropping indexes
- Aggregation pipelines
- Backup and restore with `mongodump` / `mongorestore`
- Building a REST API with Node.js, Express, and Mongoose
